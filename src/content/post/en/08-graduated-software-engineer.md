**Today I can officially say it: I'm a Software Engineer.** 🎓

This week I defended my Bachelor's Thesis and received a grade of **10/10**, the perfect ending to a chapter that changed the way I think, solve problems, and understand technology.

## The project: TripFlow

Over the past year I built **TripFlow** ✈️, an AI-assisted travel planner with real-time collaboration and offline mode.

## Under the hood

On the technical side: **microservices architecture** with Spring Boot and Java 21, **asynchronous communication** with Apache Kafka, a **React + TypeScript** frontend, **950+ automated tests**, and a full **CI/CD pipeline** deploying to production on every change.

## Try it

You can try it at 🌍 [tripflow.cub1z.es](https://tripflow.cub1z.es) and, if you want to see how it works under the hood, the code is available on GitHub 👨‍💻 [github.com/codeurjc-students/2025-TripFlow](https://github.com/codeurjc-students/2025-TripFlow).

**I'm closing a chapter, but the story goes on.** Thanks for coming along the whole way.
