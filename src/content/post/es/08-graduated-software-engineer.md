**Hoy puedo decirlo oficialmente: soy Ingeniero de Software.** 🎓

Esta semana defendí mi TFG con una calificación de **10/10**: el broche final a una etapa que me ha cambiado la forma de pensar, de resolver problemas y de entender la tecnología.

## El proyecto: TripFlow

Durante este último año he construido **TripFlow** ✈️, un planificador de viajes asistido por IA, con colaboración en tiempo real y modo sin conexión.

## A nivel técnico

Arquitectura de **microservicios** con Spring Boot y Java 21, **comunicación asíncrona** con Apache Kafka, frontend **React + TypeScript**, **+950 tests automáticos** y un **CI/CD completo** que despliega en producción en cada cambio.

## Pruébalo

Podéis probarlo en 🌍 [tripflow.cub1z.es](https://tripflow.cub1z.es) y, si os interesa ver cómo está hecho por dentro, el código está en GitHub 👨‍💻 [github.com/codeurjc-students/2025-TripFlow](https://github.com/codeurjc-students/2025-TripFlow).

**Cierro una etapa, pero la historia sigue.** Gracias por acompañarme todo este camino.
